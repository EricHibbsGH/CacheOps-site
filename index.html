Prompt-cache cost control for Claude Code

Find the money your Claude Code sessions lose to cold caches

Claude Code re-reads each conversation from a cache at a fraction of the normal price. When the cache expires, the whole conversation is written again at up to 40 times that price. CacheOps shows when that happened, what it cost, and how to stop it.

How it works

CacheOps reads the logs. It never touches your conversation.

Claude Code talks to Anthropic directly, as it always does. Afterwards, CacheOps reads the token counts Claude Code saved on your disk and turns them into a report and fixes.

Input-side cost only (cache reads and writes); output is the same in every scenario. Each request adds about 6K tokens. Cache writes cost 1.25× the input price for a 5-minute lifetime and 2× for 1 hour; reads cost 0.05× on Opus and Sonnet 5.5, 0.1× on the others. /compact is modelled as one warm re-read plus a 4K-token summary, leaving about 20K tokens.

Safety

Built for work laptops

  • Reads token counts and timestamps. Never your prompts, responses or code.
  • Never uploads anything and never touches your Claude Code login.
  • Not a proxy: it never sits between Claude Code and Anthropic.
  • Changes files only with --apply, backs them up first, and --undo restores them.

Available to invited evaluators

CacheOps is proprietary software in private evaluation. Invited evaluators receive a package file and a personal licence key. You need Node.js 20 or newer; check with node --version.

1
npm i -g ./cacheops-0.4.0.tgz
2
cacheops license activate <your key> --accept-terms
3
cacheops scan --since 30d
4

Activating accepts the CacheOps Evaluation Agreement; read it with cacheops license terms. The licence check runs offline on your computer. To remove CacheOps, undo any changes first, then uninstall:

×
cacheops fix --undo
cacheops license remove
npm uninstall -g cacheops
